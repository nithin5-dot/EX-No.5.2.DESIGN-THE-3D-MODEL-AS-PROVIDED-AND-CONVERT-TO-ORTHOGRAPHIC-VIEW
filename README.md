# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

### STEP-1:
1. Open Fusion 360
2. Select file and click new file
3. Select Part design and convert into Hybrid part
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 18122" src="https://github.com/user-attachments/assets/2c48d29c-b734-4952-8126-28cd55aa3705" />


### STEP-2:
Select sketch option and choose create sketch

### STEP-3: 
1. Create rectangle of 30 mm
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 181724" src="https://github.com/user-attachments/assets/6f274752-6e17-4d3a-8f11-9e53e1dd09c8" />
2. Select finish sketch.
 <img width="1920" height="1080" alt="Screenshot 2026-11-23 18174" src="https://github.com/user-attachments/assets/b9e04117-39f8-4b72-841a-1d53d340a31d" />

### STEP-4:
1. Use the extrude option to convert the 2D to 3D. Change the operation into New component.

2. Extrude it into 4mm.
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 184320" src="https://github.com/user-attachments/assets/98c91b90-1d52-46ca-8d4e-4a340ef93b94" />
3. Hide the bodies.
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 " src="https://github.com/user-attachments/assets/e82c8b5a-edb4-495d-87e6-d2c2331a37e9" />

### STEP-5:
1. Create the rectangle line (Horizontal of 2mm) (Vertical of 30mm)
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 182851" src="https://github.com/user-attachments/assets/b25e2707-7f0c-4902-b9e4-7a1361295dea" />
2. Select finish sketch.
3. Use the extrude option to convert the 2D to 3D. Change the operation into New component.
4. Extrude it into 2mm.
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 184544" src="https://github.com/user-attachments/assets/22ce1c99-fbc5-4d4a-a0c8-03ea3e8e121d" />

### STEP-6:
1. Copy the bodies and paste it for four bodies.
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 183817" src="https://github.com/user-attachments/assets/0adf3a7e-0d91-489d-99b8-f5cf57f9f75c" />

2. Unhide the First bodies.
3. Select the assemble option inside that select joint option.
   <img width="1920" height="1080" alt="Screenshot 2026-11-23 184012" src="https://github.com/user-attachments/assets/6c33e111-657d-4969-891d-c6f55d684d47" />

   
4. Atlast join the bodies.
